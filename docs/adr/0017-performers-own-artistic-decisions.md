# Performers own artistic decisions

The accepted target for the ongoing rhythm migration is that BeatManager, Waveforms, and authoring bases provide musical facts, edges, acquisition operations, evaluation, and access—not artistic state or policy; current production retains legacy base-owned Variant acquisition and response until the planned consumer migration and contract cut land. An Effect or Transition decides what values it holds and whether, when, and how it acquires, replaces, or responds to them; no provider or base lifecycle method does that automatically. A Mixer is one Effect at this boundary, so its child selection, configuration, suppression, unison, and composition remain its private artistic implementation rather than a standardized child-control contract; this keeps immutable providers reusable without turning them into directors of the art while allowing each Performer to use or ignore every offering.
