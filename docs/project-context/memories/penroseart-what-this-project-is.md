# What PenroseArt Is

PenroseArt is a Unity/C# real-time simulator and controller for the **Penrose Wall** LED light installation. It generates generative visual effects over a 900-tile Penrose layout, previews the wall as a Unity mesh, and outputs frames to physical LED hardware.

- **Unity version:** `6000.4.7f1 (f3c3c4248748)` from `ProjectSettings/ProjectVersion.txt`.
- **Product metadata:** company `Chuck`, product `penrose_simulator` in `ProjectSettings/ProjectSettings.asset`.
- **Primary scene:** `Assets/Scenes/SampleScene.unity` is the only enabled build scene.

Standalone API compatibility is currently `.NET Standard 2.1` via `apiCompatibilityLevelPerPlatform: Standalone: 6`; desktop `System.IO.Ports` support is supplied by platform-specific Unity plugin assets.
- **Primary source:** custom runtime scripts live under `Assets/core`, `Assets/effects`, `Assets/transitions`, and `Assets/blenders`.
- **Primary data:** Penrose geometry/mapping and palettes live in scene-serialized `Controller` fields and also in `Assets/StreamingAssets` JSON/text/image files.

## Core domain concepts

- **Penrose tile buffer:** The simulation works on a `Color[]` of `Penrose.Total == 900` logical tiles.
- **Physical LED mapping:** Hardware output expands logical tiles through `JsonRawData.wires` to 1,800 physical LEDs.
- **Effect lifecycle:** `EffectBase` subclasses are instantiated once, initialized with `Init()`, started with `OnStart()`, advanced with `UpdateTime()`, drawn every frame with `Draw()`, and optionally cleaned up with `OnEnd()`.
- **Deck selection:** `Controller.pullCard()` chooses effects/transitions from the top half of an integer deck and moves the selected card to the bottom to avoid immediate repeats.
- **Transitions:** `TransitionBase` blends between two effect buffers using effect indexes `A` and `B`, progress `V`, and remaining progress `D`.
- **Screen effects:** `ScreenEffect` subclasses draw into a rectangular `screenBuffer` and use static precomputed weights to convert that buffer into the irregular Penrose tile buffer.
- **Mixers/wrappers:** `MixerBase` effects own one or more child effects and combine or transform their buffers; `MixerBase.GetRandomEffect()` avoids picking other mixers as children.
- **Palette system:** `EffectBase.APalette` is a static `AnimPalette` shared across effects; effects usually sample colors with `APalette.read(...)`.
- **Beat system:** `BeatManager` provides a simulated BPM clock, beat variants, beat brightness, and beat-time warping for rhythmic effects.
- **Nova testing override:** `Controller.forceEffect` + `forceEffectName` can force effect selection by name substring; Escape toggles the override at runtime.

## Output and control

- Current source has file-local `#define ENABLE_SERIAL` in `Assets/core/Runtime/Controller.cs`, so the compiled frame output path is USB serial via `SerialOut` rather than E1.31/ACN UDP.
- The legacy/alternate UDP path still exists in `Controller.sendUDPFrame()` and sends E1.31-style ACN universes to the serialized IP (`192.168.1.253` in the scene).
- `OSCReader` provides OSC control defaults of local port `6969` and outbound `192.168.1.255:6161`.
- Optional systems include pixel-source blending (`PixelReceiver` on UDP port `7778`), a camera overlay (`CameraReader`, disabled in the scene), drum/ring overlays (`drums`), and a conditional telnet command server behind `ENABLE_TELNET`.
