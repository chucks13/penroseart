## Catalog cautions

- Reflection order is unsorted. Do not rely on list order unless you add and validate explicit sorting.
- Keyboard shortcuts and deck order depend on effect indexes.
- Existing lowercase class names matter because `EffectBase.Name` returns `GetType().ToString()`.
- New concrete subclasses should be parameterless because `Factory<T>` uses `Activator.CreateInstance(type)`.
