# PenroseArt Runtime Architecture

## High-level flow

PenroseArt renders every frame into a one-dimensional `Color[]` buffer for `Penrose.Total == 900` logical tiles, then mirrors that buffer into both the Unity mesh preview and the selected hardware output path.

```text
Unity scene
  -> Controller.Start()
  -> Penrose.Init()
  -> Factory-created effects/transitions/blenders
  -> Controller.Update() every frame
  -> active EffectBase or TransitionBase draws 900 colors
  -> overlays / camera / pixel blend
  -> serial or UDP hardware output
  -> Penrose.UpdateModelColors() mesh preview
```

## Scene startup

- `Assets/Scenes/SampleScene.unity` is the only enabled build scene.
- `Controller` is the main runtime hub and has script execution order `-2000` via `Assets/core/Controller.cs.meta`.
- `Controller : Singleton<Controller>` depends on `Singleton<T>.Awake()` setting `Controller.Instance` before other systems use it.
- `Penrose.Awake()` reads `JsonRawData` from `Controller.Instance.jsonSource`; this makes Controller startup order important.
- `Controller.Start()` finds `Penrose` with `GameObject.FindObjectOfType<Penrose>()`, calls `penrose.Init()`, wires UI, builds effect catalogs, starts OSC/drums/pixel receiver, creates the timer, and initializes serial output when `ENABLE_SERIAL` is active.

## Frame loop

`Controller.Update()` is the central runtime loop:

1. Updates time/timer, palette, and beat state.
1. Handles Return palette reload, Escape Nova override toggle, keyboard effect jumps, and drum test keys.
1. Draws either the active effect or the active transition.
1. Copies the active output into `penrose.buffer`.
1. Applies optional filter, drum overlay, camera overlay, and incoming pixel-source blending/replacement.
1. Sends the frame to serial output or UDP output.
1. Updates the Unity mesh colors for local preview.
1. Sends OSC ping/state.

## Penrose model

`Assets/core/Penrose.cs` owns the wall representation:

- `Penrose.Total == 900` logical tiles.
- Mesh arrays are sized `Total * 2 * 3` so each tile is represented by two triangles / six vertices.
- `JsonData` contains:
  - `Mesh`: geometry floats.
  - `tiles`: tile type, section, and neighbor data.
  - `wires`: 1,800-entry physical LED mapping.
  - `shapes`: grouped tile lists such as `loops`, `stars`, `lines0..4`, `lotusballs`, `starballs`, `mirror2`, `mirror10`.
- `GenerateMesh()` turns JSON mesh data into a Unity `Mesh` with shader `Unlit/Penrose`.
- `GenerateTiles()` derives `TileData` centers, positions, section/type, neighbors, ring, radius, angle, and tile angle.
- `UpdateModelColors()` copies each tile color into the mesh vertex colors.

## Effect system

- Top-level effects are plain C# classes, not scene components.
- `Factory<EffectBase>` reflects all concrete non-abstract subclasses and `Controller.SetupEffects()` instantiates/initializes each one once.
- `EffectBase.Init()` binds the singleton controller, Penrose instance, tile array, and `buffer`.
- `EffectBase.OnStart()` enables beat behavior and assigns a random beat variant.
- `Draw()` writes the current frame into `buffer`.
- `ScreenEffect` caches static mapping from a rectangular virtual screen to the 900 Penrose tiles.
- `MixerBase` effects create child effects and combine/transform their buffers; mixer child effects may be transient even though top-level effects are long-lived.

## Transition system

- `TransitionBase` instances are discovered by `Factory<TransitionBase>`.
- A transition owns indexes `A` and `B` into `controller.effects`, progress `V`, inverse progress `D`, and a 900-color transition `buffer`.
- When the timer expires while playing an effect, `Controller.OnTimerFinished()` starts a transition from current effect `A` to a new effect `B`, changes palette, and starts the target effect.
- When the transition timer expires, the target effect becomes the current active effect and a new transition card is drawn.

## Selection system

- `initDeck(count)` creates an integer deck `[0..count-1]`.
- `pullCard(deck)` chooses a random index from the top half of the deck and moves that selected card to the bottom.
- This deck behavior applies to effect and transition selection.
- Nova override (`forceEffect` + `forceEffectName`) bypasses the deck and picks the first effect whose `Name` contains the requested substring, ignoring case.

## Rendering pipeline

- Project uses the Built-in Render Pipeline: no custom render pipeline asset is configured in `ProjectSettings/GraphicsSettings.asset`.
- The Penrose mesh uses the custom shader `Assets/core/PenroseShader.shader` named `Unlit/Penrose`.
- ProjectSettings report Gamma color space (`m_ActiveColorSpace: 0`).
- `Penrose.UpdateModelColors()` drives preview visuals through mesh vertex colors; hardware output uses the same `penrose.buffer` data after overlays/blending.

## Important runtime side effects

- Current source scans/opens serial ports on play because `Controller.cs` defines `ENABLE_SERIAL` locally.
- Runtime opens UDP listeners for OSC (`6969`), pixel receiver (`7778`), and drums (`8500`).
- `kscope` can rewrite `Assets/StreamingAssets/images/*/files.txt` on non-Android.
- Telnet server is inactive by default, but if `ENABLE_TELNET` is enabled it listens on port `23` and appends to root `log.txt`.
