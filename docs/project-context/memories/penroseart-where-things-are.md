# Where Things Are in PenroseArt

## Top-level layout

| Path                                        | Purpose                                                                                                                                 |
| ------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `Assets/`                                   | Unity assets and all project-authored runtime code.                                                                                     |
| `Assets/Scenes/SampleScene.unity`           | Only enabled build scene; contains `Controller`, `PenroseDisplay`, UI, camera, and event system.                                        |
| `Assets/core/`                              | Main runtime systems: controller, Penrose mesh/model, bases, output, input/OSC, camera/drum overlays, shader, protocol docs.            |
| `Assets/core/helpers/`                      | Small utilities and support classes: factory, palette, singleton, timer, extension methods, telnet server, blender base, slider script. |
| `Assets/effects/`                           | Generative visual effects and mixer/wrapper effects discovered by reflection.                                                           |
| `Assets/transitions/`                       | `TransitionBase` subclasses used to blend between effects.                                                                              |
| `Assets/blenders/`                          | External-source blenders for mixing native visuals with incoming pixel data.                                                            |
| `Assets/StreamingAssets/`                   | Runtime-loadable data: Penrose geometry/mapping JSON, palettes, image lists, and images for `kscope`.                                   |
| `Assets/TextMesh Pro/`                      | Imported TMP resources/examples; not central Penrose logic.                                                                             |
| `Packages/manifest.json`                    | Direct Unity package dependencies.                                                                                                      |
| `Packages/packages-lock.json`               | Resolved package lock; should stay committed for reproducible Unity package resolution.                                                 |
| `ProjectSettings/`                          | Unity project/player/editor/build settings.                                                                                             |
| `.vscode/`                                  | VS Code Unity settings, VSTU attach config, and recommended extension.                                                                  |
| `.vsconfig`                                 | Visual Studio managed-game workload hint.                                                                                               |
| `Assembly-CSharp.csproj`, `penroseart.slnx` | Unity-generated C# project/solution files; generated and generally not hand-edited.                                                     |

## Effects, transitions, and blenders

Effects are discovered at runtime by `Factory<EffectBase>` from concrete non-abstract subclasses.

- `Assets/effects/`: `Angles`, `AnimateLoops`, `ColorSparkle`, `Flock`, `Julia`, `MetaBalls`, `Mirror`, `Nibbler`, `Noise`, `NoiseMixer`, `NoiseTunnel`, `Panels`, `Petals`, `Pulse`, `RainbowBars`, `RandomEffectsMixer`, `Ripple`, `ShapeGlitch`, `TileShapes`, `Tunnel`, `Vortex`, `Waterfall`, `fluid`, `kscope`, `lightning`, `yinyangmixer`.
- `Assets/transitions/`: `DirectionalWipe`, `Fade`, `FizzleTransition`, `IndexWipe`, `IrisTransition`, `NoiseTransition`, `RGBFade`.
- `Assets/blenders/`: `RGBBlender`, `SilhouetteBlender`.

## Runtime data locations

- `Assets/Scenes/SampleScene.unity` serializes large inline `Controller.paletteSource` and `Controller.jsonSource` fields.
- `Assets/StreamingAssets/rawdata.json` and `rawdata1.json` both contain 900 tiles, 1,800 wires, 10,800 mesh floats, and shape lists such as `loops`, `stars`, `lines0..4`, `lotusballs`, `starballs`, `mirror2`, and `mirror10`.
- `Assets/StreamingAssets/palettedata.txt`, `jenpalettes.txt`, and scene `paletteSource` feed `AnimPalette`.
- `Assets/StreamingAssets/images/color` and `Assets/StreamingAssets/images/mono` feed the `kscope` image effect; `kscope` can write `files.txt` lists on non-Android runtime.
