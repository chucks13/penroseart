Problem

The Director's interface to live music is shallow: it must know raw OSC fields, PhaseClock confidence, Phrase Window planning, selected Phase Boundary cursor state, coasting, and rewinds.

Solution

Create one in-process on-air timing module whose interface returns the current selected Phase Boundary, confidence, reason, and cursor state.

Wins

  • locality: phase bugs concentrate
  • interface names phase vs phrase
  • tests hit one interface
  • Director stops parsing OSC
  • loop policy becomes explicit
ADR fit: this preserves ADR-0004. The Director still directs; the new module only interprets on-air timing.

Problem

Drop preference is computed, logged, then discarded: synced transitions call StageNextChoices(Repertoire.None) after starting.

Solution

Make cue intent a small value the Director consumes when staging the following move; keep effect expression inside effects.

Wins

  • leverage: Repertoire earns keep
  • Drop intent stops leaking
  • tests name cue behavior
  • effects still express
  • Director still decides
Open design point: no current Effect advertises non-None Repertoire, so this is not yet a pure polish slice.

Problem

A broad cleanup could accidentally flatten the useful modules that made the current behavior testable.

Solution

Polish by replacing shallow Director-owned glue, not by deleting the pure modules already carrying behavior behind small interfaces.

Wins

  • depth already proven
  • tests stay meaningful
  • no speculative adapters
  • behavior stays visible
  • polish has boundaries

Top recommendation

Deepen on-air timing interpretation first
