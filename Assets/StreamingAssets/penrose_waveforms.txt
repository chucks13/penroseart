// Format, one Preset per line:
//   DEFINE_WAVEFORM(name){ sequence | amplitude | rounding | offset }
//   sequence   note-value tokens per Hump: W=whole(4) H=half(2) Q=quarter(1) E=eighth(1/2) S=sixteenth(1/4);
//              widths sum to one bar (4/4).
//   amplitude  one digit 0-8 per Hump, read straight across (digit/8 -> [0..1]). 0 is the gate: a
//              silent Hump = a skipped beat.
//   rounding   0..1 peak shape: 0 sharp triangle -> ~0.5 cosine dome -> 1 flat top.
//   offset     phase shift in beats; 0.5 lands on the "&" (offbeat).
//
// Entry order is preserved for authoring. Runtime performers acquire by Energy or uniformly across
// the whole Pool; no performer stores a row index.
